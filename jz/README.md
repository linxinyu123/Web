# Cashew 记账 · Neco Edition 5

## 部署到现在的网站

1. 将本文件夹中的 `index.html`、`manifest.webmanifest`、`sw.js` 和整个 `icons` 文件夹一起上传至现有记账网站的目录，例如 `/jz/`。
2. 保持原来的 HTTPS 域名。不要只上传 HTML；安装与离线使用需要旁边的文件。
3. `manifest.webmanifest` 建议以 `application/manifest+json` 返回；`sw.js` 以 JavaScript 类型返回并设置 `Cache-Control: no-cache`。
4. 在 Android Chrome 打开该目录，等待浏览器完成检测后，从「我的 → 安装 Cashew」或 Chrome 菜单选择「安装应用」。
5. 安装后应可从应用列表启动，在独立窗口中打开，不带网页地址栏。在系统「设置 → 应用」中确认是否出现 Cashew。

Chrome 是否生成 WebAPK 也取决于设备上的 Google Mobile Services 和安装服务。若仅能创建带 Chrome 标记的快捷方式，不代表已完成独立应用安装。请确认 HTTPS、资源没有 404、manifest 可访问、图标正确，以及设备的 Play 服务可用。

官方说明：https://web.dev/learn/pwa/installation

## 数据与升级

- 仍使用原有的 `cashew.html.v1` 本地数据键。在相同浏览器、相同 HTTPS 域名和端口部署时会继续读取已有账本。
- 本地 HTML、其他域名或其他浏览器有各自的数据空间。需要迁移时，先在旧页面导出完整 JSON，再在新页面导入。
- 离线支持手动记账、账本、日历和统计。Gemini 识别需要联网。
- 缓存只保存应用文件，不缓存 AI 请求、API 密钥或个人账单。
- 更新不会强制刷新正在填写的表单。关闭已有应用窗口再重新打开即可使用新版本。
- 成员和支付状态已从记账、详情与筛选界面移除。旧文件中的支付标记仅保留数据兼容用途，避免升级时改变已有账户余额。
