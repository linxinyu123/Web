# 对读 · PDF 工作空间

一个浏览器里的 PDF 工作台。首次打开进入最近文件主页，再次打开恢复上次的标签、顺序、当前文档与阅读位置。自动保存最近 60 份文件，支持双栏联动、搜索、深色阅读和高清图片导出。

## 打开

- **直接使用：** 双击 `index.html`。界面、样式、交互都打包在这一个文件里；打开 PDF 时需要联网加载 PDF.js。也可以单独把这个文件上传至原有静态网站。
- **离线使用：** 双击 `启动对读.cmd`，或运行 `python serve.py`，在浏览器打开 <http://127.0.0.1:4173/>。保留 `vendor/` 文件夹后，PDF 引擎、字体、CMap 和解码器均从本地加载，无需 npm 或构建步骤。Python 需要已安装。
- **静态部署：** 上传 `index.html`、`icon.svg` 和 `vendor/`；HTTP/HTTPS 下优先使用本地资源，缺少引擎时才回退到 CDN。

同一地址、同一浏览器保留相同的阅读历史。`file://`、`localhost`、`127.0.0.1` 和不同端口拥有各自独立的浏览器存储；推荐固定使用一个地址。浏览器清除网站数据会移除文件副本和进度。PDF 内容始终在本机解析。

## 操作

- 主页打开文件，支持一次选择多个 PDF，也支持拖入。主页标签始终保留，文档标签支持关闭、中键关闭、拖动排序、左右方向键切换。
- 返回主页不会关闭正在阅读的文档。刷新时恢复上次选中的标签，后台 PDF 按需恢复。支持右键关闭其他标签、关闭右侧标签，及重新打开已关闭标签。
- 最近文件支持名称搜索、收藏、排序、列表与卡片视图，以及移除后撤销。
- 点击“双栏对读”，分别在两侧打开文件；保留原有同步滚动、翻页、缩放和文字选择映射功能。
- 阅读工具栏的月亮按钮切换 PDF 深色阅读；“阅读偏好”可选原色、柔和深色、完全反色和暖色纸张。界面主题独立控制，可跟随系统。
- 反色应用于 PDF 的渲染位图，覆盖文字、扫描件和图片，同时保留原有文字选择与搜索。完全反色也会改变图片和图表颜色，原始 PDF 文件不被修改。
- 手机和平板：单指原生惯性滚动、双指锚点缩放、双击放大或适宽；阅读工具收纳到“全部阅读工具”，转图片保留快捷入口。窄屏主页使用底部导航。
- PDF 转图片：在阅读器点击“转图片”，选择当前或其他 PDF，输入 `1-5, 8, 10-12` 等范围；支持 150 / 300 / 450 / 600 DPI、PNG / 高质量 JPG 和自定义文件名前缀。自动添加原始页码，例如 `报告_page-0008.png`。逐页转换，可取消。
- 默认使用指定文件夹：选择 Downloads 后，会创建 `Downloads/PDF名称/`，逐页保存图片，避免覆盖已有图片；同一次打开网页时记住所选目录。浏览器需先获得目录写入授权。不支持目录写入的浏览器仍提供兼容下载方式。单页像素和 ZIP 总大小有保护上限，过大的页面会提示降低 DPI，不会静默降低质量。

| 操作 | 快捷键 |

| 打开文件 | Ctrl / ⌘ + O |
| 返回主页 | Alt + T |

## 实现与维护

没有前端框架依赖。首页不加载 PDF 引擎，文档使用 Web Worker 解析、可见页优先渲染、分级清晰度和受限画布缓存。后台标签缩小预览，最多保留两个后台阅读现场，其余释放 Worker 和页面资源，再次激活时恢复阅读进度。

`shell.html` 和 `workspace.css` 组织页面，`design-system.css` 统一黄色主题、字体、圆角、对齐与控件。`workspace.js` 管理标签和历史；`controls.js` 实现自绘选择器和弹窗；`touch.js` 处理触控；`image-export.js` / `image-export-core.js` 处理逐页图片输出与 ZIP。

`prepare_workspace.py` 基于 `.backups/index-before-workspace.html` 保留原阅读器，并生成可独立复制的 `index.html` 和调试用 `app.js` / `reader.css`。修改源文件后运行 `python prepare_workspace.py`。Nunito 字体已嵌入，许可在 `fonts/OFL.txt`；PDF.js 6.3.289 的许可在 `vendor/pdfjs/LICENSE`。

检查：`python .qa/check_static.py`、`node .qa/test_core.cjs`。浏览器验证记录位于 `.qa/verification.md`。`.qa/`、`.reference/` 和 `.backups/` 不需要上传，内置本地服务器不提供隐藏目录。
